# Daily proverb seed data

`daily-proverbs.json` contains a curated 365-item subset of the human-validated
VIVID Vietnamese idiom and proverb dataset:

- Source: https://github.com/ReML-AI/VIVID
- Dataset: `dataset/VIVID_Dataset.csv`
- License: MIT; see `VIVID-LICENSE.txt`

The application does not generate these sayings. Each row retains the original
Vietnamese expression and explanation from the cited dataset.
